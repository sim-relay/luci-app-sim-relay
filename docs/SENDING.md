# 0.4 短信发送

[English](USAGE.md#sms-and-retention) | 简体中文

LuCI 提交号码、正文和请求 key，后台在 /tmp 创建临时操作文件，轮询进程顺序执行。设备身份、SIM、编码、认证挑战和发送结果确认仍复用 ZTE 协议实现。

手动发送不自动重试。结果不明时显示 unconfirmed，由用户查看设备后决定是否重新发送，不再通过永久记录阻塞其他操作。请求 key 在当前运行缓存/队列中可查回原结果，重启清空最近记录后不再保证幂等。

转发短信遵循不同的简单规则：只有确认成功才删除待转发标记，失败或结果不明都保留并重试，因此可能重复，见 [转发设计](PUSH.md)。

ZTE 支持 GSM 与 Unicode BMP，Unicode 最多 335 字符，不支持发送 emoji，设备本地发送时间使用 UTC+8。本机 ModemManager 设备通过 UTF-8 临时文件传递正文（最多 8192 字节），支持 emoji/引号/换行，由 ModemManager 处理编码与分段。临时文件权限 0600，创建完成后删除。真实设备发送确认仍需实测。
