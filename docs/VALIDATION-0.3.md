# 0.3 新增功能验证

本轮实现 SIM/PIN、设备批量删除与保留策略、共享推送通道及可选 SMTP，数据库升级至 schema 5。

## 已验证

- 本机 x86-64 C 构建通过，开启 `-Wall -Wextra -Wpedantic -Werror`。
- Python 回归测试 69 项：65 通过，4 项真实 HTTP 测试因沙箱禁止套接字跳过。
- CTest 两组通过：短信编码/日期/身份、推送格式/飞书签名/SMTP 进程与匿名配置描述符。
- 相同测试在 AddressSanitizer / UndefinedBehaviorSanitizer 构建中通过。
  LeakSanitizer 不适用于当前环境，已显式关闭，不包含泄漏检测结论。
- 三个 LuCI 页面语法检查通过，页面 RPC、后台方法签名与 ACL 一致性检查通过。
- 构建脚本 Bash 语法检查通过，0.2 历史 IPK 在增强后的检查器下仍通过检查。
- strip 后本机 ELF：116,928 B（约 114.2 KiB），不含共享库，不能当作 OpenWrt 包大小。

本机缺少 libsodium 开发包，本地链接测试使用临时稳定 API 声明和系统 libsodium 运行库。
正式源码包含官方 `sodium.h`；OpenWrt SDK 将使用依赖包提供的官方头文件，因此仍需正式 SDK 重建。
本地临时声明不进入仓库或安装包，不能替代 SDK 的编译兼容性验证。

## 回归重点

- PIN 密文和所属 ICCID 绑定，自动尝试仅在 3 次剩余机会且无闭锁时执行。
- 密钥丢失、权限异常、密文篡改、PIN 设置版本变化和提交中断均不会触发盲目重试。
- 删除操作要求完整身份和唯一槽位，槽位复用会拒绝，不会删除新占用记录。
- 硬件保留策略使用实时硬件日期；本地先清正文也不会影响硬件清理顺序。
- 旧外部身份转换为摘要，原有删除标记不会失效。
- 每绑定历史基线、通道版本、显式删除/解绑时取消待发短信、持久化测试幂等、SMS 转发未知结果与明确失败重试。
- 设备改名不改变待发内容指纹；队列满时回滚同步，不丢弃待转发记录。
- SMTP 密码不在 argv，配置通过已 unlink 的 0600 文件描述符传递；非零结果不假定未发送。
