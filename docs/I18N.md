# 0.6 语言包

默认主后台和 LuCI 应用只提供英文原文。简体中文通过独立的 `luci-i18n-sim-relay-zh-cn` 包提供，不是主包依赖；卸载语言包即可回退英文。用户的短信正文、设备名称等数据保持原样。

采用 OpenWrt/LuCI 原生机制：

- JS 文案使用 `_("English message")`，菜单 JSON 的 title 也使用英文。
- `luci-app-sim-relay/po/templates/sim-relay.pot` 是英文模板。
- `luci-app-sim-relay/po/zh_Hans/sim-relay.po` 是简体中文译文。
- 由现有 `luci.mk` 自动生成独立翻译包，使用官方 po2lmo 编译为 `sim-relay.zh-cn.lmo`，并注册 LuCI 的简体中文语言选项。没有自制 LMO 编译器、重复页面或运行时 gettext 依赖。
- 主包不安装 PO/POT/LMO，也不强制依赖语言包。中文包只安装编译后的翻译和标准语言注册脚本，依赖 LuCI 应用。
- 后台原有中文错误提示已统一为英文，页面按相应 message ID 翻译显示。其他动态错误若尚无译文则回退英文。

`zh_Hans` 到 `zh-cn` 的包名映射、PO 编译和包安装均由 [OpenWrt 24.10 luci.mk](https://github.com/openwrt/luci/blob/openwrt-24.10/luci.mk) 提供。

## 编译与安装

SDK 脚本默认同时编译英文主包和独立中文语言包。构建后仍按需选择安装，编译中文包不代表主包会强制安装它。

```sh
sudo -n env WITH_ZH_CN=1 WITH_MM_PIN=1 WITH_SMTP=1 EXPECT_ELF_MACHINE=62 bash scripts/build-sdk.sh
```

只构建英文版：

```sh
sudo -n env WITH_ZH_CN=0 EXPECT_ELF_MACHINE=62 bash scripts/build-sdk.sh
```

中文包的产物名为 `luci-i18n-sim-relay-zh-cn_<版本>_all.ipk`。主包安装后，可通过系统软件包界面或命令安装该 IPK：

```sh
opkg install /tmp/luci-i18n-sim-relay-zh-cn_*.ipk
```

然后在 LuCI 的语言设置中选择简体中文并刷新页面；自动语言模式也可按浏览器语言选择。该语言包只翻译 SIM Relay，LuCI 系统界面需要时另安装 `luci-i18n-base-zh-cn`，不由本应用强制拉取。

后续增加其他语言，只需按 LuCI 的语言目录名称增加 `po/<语言>/sim-relay.po`，沿用同一英文页面与菜单。

## 验证

`python3 scripts/check-i18n.py` 检查菜单和页面静态原文是否有中文译文，并检查模板与 PO 的一致性。页面逻辑测试分别覆盖英文和中文；SDK 检查器检查语言包、LMO、依赖和主包内容的隔离。

中文包已通过 SDK 实际构建并安装到 ImmortalWrt 测试路由器。页面逻辑测试使用 DOM 和 RPC 替身，不能替代所有真实浏览器与语言设置组合的测试。
